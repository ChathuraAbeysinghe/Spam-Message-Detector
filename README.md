# 🛡️ AI Spam Message Detector

An end-to-end Machine Learning web application that classifies SMS messages as **Spam** or **Not Spam (Ham)** using Natural Language Processing (NLP).

Built with Python, Scikit-learn, FastAPI, and a responsive web interface.

## ✨ Features

- 🤖 ML-based SMS spam detection
- 🧠 TF-IDF and Multinomial Naive Bayes
- 📊 Model evaluation with Accuracy, Precision, Recall, and F1-Score
- 🌐 FastAPI REST API with Swagger documentation
- 📱 Responsive interface for mobile, tablet, and desktop
- 📁 Batch message classification and CSV upload
- 🕘 Prediction history, statistics, and CSV export
- 🧪 Automated testing with Pytest
- 📈 User feedback for incorrect predictions

## 🛠️ Technology Stack

- **Language:** Python 3.10+
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas, NumPy
- **Backend:** FastAPI, Uvicorn
- **Frontend:** HTML, CSS, JavaScript
- **Model Storage:** Joblib
- **Database:** SQLite
- **Testing:** Pytest
- **Alternative UI:** Streamlit

## 📂 Dataset

**UCI SMS Spam Collection**

- 5,572 English SMS messages in the original dataset
- Two classes: `spam` and `ham`
- Data cleaning and duplicate removal
- Stratified 80/20 train-test split

Dataset: https://archive.ics.uci.edu/dataset/228/sms+spam+collection

## 🧠 Machine Learning Workflow

1. Download and clean the dataset.
2. Split data into training and testing sets.
3. Extract text features using TF-IDF.
4. Train the Multinomial Naive Bayes classifier.
5. Evaluate the model using classification metrics.
6. Save the trained model using Joblib.
7. Integrate the model with the web application and REST API.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Spam-Message-Detector.git
cd Spam-Message-Detector
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Train the Model

```bash
python train_model.py
```

### 5. Run the Web Application

```bash
python app.py
```

Open the application:

- Web App: http://localhost:8000
- API Documentation: http://localhost:8000/docs

### 6. Run Tests

```bash
pytest -v
```

## 📊 Model Evaluation

The project uses the following metrics:

- **Accuracy:** Overall classification correctness
- **Precision:** How many predicted spam messages are actually spam
- **Recall:** How many actual spam messages are detected
- **F1-Score:** Balance between precision and recall

Evaluation results should be generated by running the training script. Do not treat example results as guaranteed performance.

## ⚠️ Limitations

- Primarily trained on English SMS messages.
- May struggle with disguised spam words and unfamiliar message patterns.
- Predictions are statistical estimates, not guaranteed decisions.
